# 1. Application Overview

Nila has two primary participants:

### Child

The paying/configuring user.

The child:

- creates an account
- adds a parent
- configures calls
- receives summaries
- reviews changes
- follows up with the parent

### Parent

The person receiving the AI voice calls.

The parent:

- receives the call
- talks naturally with Nila
- can answer or decline questions
- can end the conversation
